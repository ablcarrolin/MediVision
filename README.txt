MediVision — Multi-page website

Pages:
- index.html: Beranda
- scan.html: AI Body Scan demo
- doctors.html: Konsultasi Dokter
- articles.html: Artikel Edukasi
- about.html: Tentang Kami
- contact.html: Kontak

All pages share style.css and script.js. Navbar links navigate between separate HTML files.

Run by opening index.html or using VS Code Live Server. Internet is required for Pexels-hosted images and Google Fonts.

Important: scan is only a visual UI simulation, not medical diagnosis or real body scanning.
